# Smart Parking

Университетский командный проект по разработке системы умной парковки.

## Разработка

- `frontend/` — клиентская часть.
- `backend/` — серверная часть.
- `main` — стабильная версия проекта.
- `develop` — ветка разработки.

Задачи ведём в GitHub Issues. Инструкция по работе с репозиторием — в CONTRIBUTING.md.
