# Smart Parking

Университетский командный проект по разработке системы умной парковки.

## Разработка

- `frontend/` — клиентская часть.
- `backend/` — серверная часть.
- `main` — стабильная версия проекта.
- `develop` — ветка разработки.

Задачи ведём в GitHub Issues. Инструкция по работе с репозиторием — в CONTRIBUTING.md.

Веб-приложение для поиска парковки и просмотра свободных мест. Данные о местах уже входят в проект, поэтому для демонстрации достаточно запустить фронтенд.

## Первый запуск

Откройте терминал в корне репозитория, рядом с папкой `frontend`. Для проекта используется Node.js **24.11.1** с npm. Если пользуетесь nvm, после перехода в `frontend` выполните `nvm install` — версия указана в `.nvmrc`.

```sh
cd frontend
npm ci
npm run dev
```

Откройте адрес из строки **Local** в терминале. Обычно это `http://localhost:5173`. Если порт занят, Vite выберет следующий, например `http://localhost:5174`.

На стартовом экране выберите **«Войти» → «Подставить демоданные» → «Войти»**. Откроется карта с тремя демопарковками в Москве. Нажмите на метку или название в списке, чтобы открыть схему мест.

Чтобы остановить приложение, нажмите **Ctrl+C** в терминале. Для следующего запуска из папки `frontend` достаточно `npm run dev`.

## Карта и поиск адресов

Первый запуск можно выполнить без ключей. При подключении к интернету базовая карта использует OpenStreetMap. Для Яндекс Карт, резервной карты 2ГИС и поиска адресов укажите публичные ключи в `frontend/.env.local`.

Если у вас уже есть `.env.local`, откройте его для редактирования. При первой настройке в папке `frontend` выполните `cp -n .env.example .env.local`, затем впишите свои ключи в созданный файл.

| Переменная | Что включает |
| --- | --- |
| `VITE_YANDEX_MAPS_KEY` | Основная карта. Нужен ключ Яндекс Карт с доступом к JavaScript API. |
| `VITE_2GIS_MAP_KEY` | Поиск по адресу через Geocoder API и резервная карта через Raster Tiles API. |

После изменения ключей перезапустите `npm run dev`. Для локального запуска укажите `localhost` среди разрешённых доменов ключа Яндекса, для опубликованного сайта — его домен.

## Проверка на телефоне

Подключите телефон и компьютер к одной сети Wi-Fi. Остановите текущий запуск и выполните команду в папке `frontend`.

```sh
npm run dev -- --host 0.0.0.0
```

На телефоне откройте адрес из строки **Network** в терминале. Список парковок и схема мест доступны и в случае, если ограничения ключа не разрешают загрузить основную карту по локальному IP.

## Сборка и размещение на сервере

Эти команды проверяют проект, создают сборку и запускают её локальный просмотр. Выполните их в папке `frontend`.

```sh
npm test
npm run build
npm run preview
```

Откройте адрес **Local** из вывода последней команды. Для размещения на сервере скопируйте содержимое `frontend/dist/` в корень статического сайта. Настройте выдачу `index.html` для маршрутов приложения, чтобы обновление страницы на `/map` или `/parkings/open-lot` работало по прямой ссылке. Ключи карт подставляются при сборке, поэтому после их смены повторите `npm run build` и загрузите обновлённые файлы.

Пример настройки nginx, сценарий демонстрации и описание источника данных есть в [документации фронтенда](frontend/README.md).
