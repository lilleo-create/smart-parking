# Трекер парковки на Raspberry Pi

Трекер получает видео с камеры, распознаёт машины через YOLO и отслеживает их с ByteTrack. Веб-интерфейс показывает кадр, занятость мест и редактор разметки. Разметка и текущая занятость хранятся в локальной SQLite.

## Запуск с USB-камерой

Выполни команды из каталога `backend/parking-tracker`. На Raspberry Pi использовался Python 3.11.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

В другом терминале из того же каталога запусти трекер с моделью для макета.

```bash
.venv/bin/python parking.py --source 0 --size 320 --model parking-toy-v1.pt --classes 0
```

`--source` принимает номер USB-камеры, путь к видео или адрес видеопотока. Для настоящих машин используй стандартные веса YOLOv8n и классы по умолчанию, запустив `parking.py --source 0 --size 480` через тот же Python. При первом запуске может потребоваться загрузка стандартных весов. Модель `parking-toy-v1.pt` дообучена на трёх игрушечных машинках для демонстрации на макете.

## Веб-интерфейс

Сервер доступен на `127.0.0.1:8765` на самой Pi. Для доступа с другого компьютера открой SSH-туннель.

```bash
ssh -N -L 8875:127.0.0.1:8765 YOUR_PI_USER@YOUR_PI_HOST
```

Открой [интерфейс парковки](http://127.0.0.1:8875/). Нажми **«Разметить места»**, протяни по кадру для добавления места и нажми **«Сохранить»**. Сохранённое место можно выбрать на кадре или по номеру в списке, затем изменить его номер или удалить его.

Для отправки событий `space.occupied` и `space.freed` задай `PARKING_WEBHOOK_URL` и, если нужно, `PARKING_WEBHOOK_TOKEN` в окружении процесса `server.py`.

## Передача разметки и статусов на сайт Smart Parking

Оставь `parking.py` и `server.py` запущенными. Разметь места в веб-интерфейсе, затем в третьем терминале из `backend/parking-tracker` запусти отправщик.

```bash
python3 publish_snapshot.py \
  --url https://smart-park.my-uzel.xyz/api/tracker/snapshot \
  --token-file /path/to/tracker-token
```

Попроси владельца сайта передать токен приватно и укажи путь к файлу, который может читать только пользователь отправщика (`chmod 600`). По умолчанию отправщик читает `output/status.json`. Для другого каталога вывода укажи `--status ПУТЬ/status.json`.

Открой [Smart Parking](https://smart-park.my-uzel.xyz), войди через «Подставить демоданные» и выбери «Парковка на макете». Сайт получает номера из редактора, добавляет и убирает места вместе с разметкой и обновляет занятость без перезагрузки.
