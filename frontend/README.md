# Smart Parking · фронтенд

Веб-демо показывает доступность мест на трёх демопарковках рядом с выбранным адресом. Работает на локальных примерах, без сервера и камеры. Схема адаптируется к десктопу, мобильным и горизонтальным экранам.

[Исходный макет в Figma](https://www.figma.com/design/rYLLiBNcol25YBopni3pQr/smart-parking-web?node-id=0-1)

## Запуск

Установка Node.js, команды первого и повторного запуска, проверка на телефоне и публикация описаны в [инструкции по запуску](../README.md).

Открыть локальный адрес, напечатанный Vite. Выбрать «Войти» → «Подставить демоданные» → «Войти». Тестовый логин — `driver`, пароль — `parking123`. Регистрация открывает демосессию с вымышленными данными. После выхода для повторного входа используется общий тестовый профиль. В хранилище вкладки сохраняются признак демосессии и параметры размещения демонстрационных парковок. Для настоящих учётных записей потребуется серверная авторизация.

## Демонстрация

1. Войти или зарегистрироваться. Кнопка «Подставить демоданные» доступна в обеих формах.
2. Ввести адрес для поиска или оставить начальную карту Москвы. Метки показывают число свободных мест.
3. Нажать на метку или название парковки в списке. Схема показывает занятость автоматически. Нажать на свободное место и выбрать «Проложить путь» до указанного номера. Если место занято или наблюдение устарело, маршрут снимается. После парковки нажать на занятое место, чтобы запомнить его. Кнопка «Моя машина» на карте возвращает к отметке. После выезда нажать «Я уехал». Отметка хранится в этом браузере.

Поиск использует Geocoder API 2ГИС с ключом `VITE_2GIS_MAP_KEY`. Текст запроса отправляется при нажатии «Найти». Выбранный на обзорной карте адрес сохраняется в текущей вкладке до выхода из демопрофиля.

## Карта и размещение

Основная карта использует Яндекс JavaScript API 3. При первом открытии видны все три парковки. Масштаб меняется колёсиком, жестами или кнопками. «Все парковки» возвращает общий вид. Для Яндекс Карт скопировать `.env.example` в `.env.local`, задать публичный ключ `VITE_YANDEX_MAPS_KEY` для JavaScript API и перезапустить Vite. Для локальной разработки открыть http://localhost:5173 и указать в кабинете ключа домен `localhost` в поле «Ограничение по HTTP Referer» без протокола и порта. По документации Яндекса изменения ограничений применяются через 15 минут. [Быстрый старт](https://yandex.ru/maps-api/docs/js-api/common/quickstart.html).

Для резервной карты 2ГИС указать ключ Raster Tiles API в `VITE_2GIS_MAP_KEY` в файле `.env.local` и перезапустить приложение. При недоступности Яндекс Карт приложение автоматически открывает 2ГИС. Пока ключ 2ГИС пуст, в демо доступна OpenStreetMap. Если настроенная карта 2ГИС тоже недоступна, парковку можно выбрать из списка. [Демо-ключ 2ГИС](https://docs.2gis.com/platform-manager/demo-key).

Для загрузки подложки карты и поиска адреса нужен интернет.

Проверки обновления парковок и актуальности мест запускаются из папки `frontend` командой `npm test`.

```sh
npm run build
npm run preview
```

Для размещения на сервере раздать содержимое `dist/` из корня сайта. При прямом открытии `/parkings/open-lot` сервер должен вернуть `index.html`. Для хостингов с поддержкой `_redirects` правило уже входит в сборку. Для nginx в существующем блоке сайта использовать `location / { try_files $uri $uri/ /index.html; }`. Для смены ключа на хостинге собрать приложение заново.

## Подключение бэкенда

Типы описаны в `src/data/parking.ts`. Объект `source` в `src/data/demo.ts` реализует три асинхронные операции. Для подключения API заменить источник в слое данных. Компоненты карты и схемы читают общее состояние из `src/data/state.ts`. Возможные серверные маршруты:

| Операция | Маршрут | Результат |
| --- | --- | --- |
| listParkings | GET /api/parkings | Доступные водителю парковки с последними снимками |
| getParking | GET /api/parkings/{id} | Название, адрес, координаты въезда и массив мест. Каждое место имеет стабильный id, подпись, секцию, ряд и позицию |
| getOccupancy | GET /api/parkings/{id}/occupancy | Снимок статусов одной парковки |

В `src/data/demo.ts` параметр `layout` каждой демопарковки задаёт секции, ряды и число мест в ряду. Поле `sectionColumns` задаёт число секций в одном ряду плана. Положение секций, мест и въезда сохраняется при изменении размера экрана. Если план не помещается, его можно прокручивать по обеим осям. Сейчас используется общая схема из четырёх секций по шесть мест (24 на парковку). При настройке макета сохраняйте обозначения существующих рядов и мест, чтобы ранее сохранённые отметки и наблюдения камеры по-прежнему указывали на нужное место. Пример частичного снимка для момента проверки 10:00:05 UTC:

```json
{
  "parkingId": "open-lot",
  "observedAt": "2026-11-21T10:00:00Z",
  "validUntil": "2026-11-21T10:00:15Z",
  "statuses": { "A1": "occupied", "A2": "free", "A3": "free", "B1": "free", "B2": "occupied", "B3": "occupied" }
}
```

В 10:00:15 UTC тот же снимок становится устаревшим. До следующего наблюдения места получают состояние «Нет данных». Пропущенное место или явное значение `unknown` также исключается из числа свободных. Личная отметка хранится у водителя. Счётчики и схема берут занятость только из наблюдений: когда камера сообщит о свободном месте, оно станет доступным независимо от отметки. Устройство в дальнейшем отправляет наблюдения серверу, а веб-клиент получает уже сопоставленные идентификаторы мест.

Старые ссылки с окончанием `/drive` открывают схему той же парковки. Выпуск для CarPlay и Android Auto требует отдельных платформенных клиентов.
